# JARVIS HUD Web UI

This folder contains the Google AI Studio web application scaffold for the futuristic JARVIS HUD.

## Run

```bash
cd web
npm install
npm run dev
```

Set `GEMINI_API_KEY` in the environment for the current server-side chat endpoint.

## Important

The current GitHub tree contains the AI Studio root/config files, but the referenced React source entry `src/main.tsx` is not currently present in the repository. The UI source should be placed under `web/src/` before this app can build successfully.
